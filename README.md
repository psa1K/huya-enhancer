# 虎牙直播增强

一个用于 **虎牙直播** 的用户脚本：自动跳过扫码限制的画质，并自动切换到最高画质或你指定的画质；同时可屏蔽广告推广、礼物特效与推荐直播等无关内容。通过 Tampermonkey / Violentmonkey 等浏览器扩展运行。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
   （Chrome / Firefox / Edge 均支持，Violentmonkey 同样适用）

2. 以下方式任选其一：

   点击 [huya-enhancer](https://github.com/psa1K/huya-enhancer/raw/refs/heads/main/huya-enhancer.user.js) 安装

   或前往 [Greasyfork](https://greasyfork.org/zh-CN/scripts/542837) 安装

## 功能

- 无需扫码解锁最高画质
- 默认自动切换到最高画质
- 可选：自动切换到指定画质
- 自动进入剧场模式（默认关闭，可在脚本菜单开启）

## 新增功能

在原「自动切换画质」基础上新增：

- **屏蔽无关内容**（默认全开，可逐项开关）：广告推广（直播间头图、主播区 banner、游戏推广、侧栏广告位、赛事 CMS 嵌入）、礼物特效（礼物占位、宝箱、大主播舞台、弹幕区收礼 / 贵族进场提示）、推荐直播（猜你喜欢、推荐分类、推荐 / 主播动态、讨论区、左侧栏推荐分类）
- **播放器内嵌设置入口**：在礼物栏「充值」左侧注入一个齿轮按钮，点开即可调整视图、画质与屏蔽项（与脚本菜单读同一份配置）

以上均可在脚本菜单或内嵌齿轮入口逐项开关，设置实时保存。

## 配置（脚本菜单）

无需编辑代码——点击浏览器右上角篡改猴图标，在本脚本的菜单中设置；也可直接在播放器礼物栏「充值」左侧的齿轮按钮里设置（两者等价）：

- **视图**：默认 / 剧场（默认为默认）
- **画质**：自动列出当前直播间的可选画质；「跟随房间最高」为默认行为，「手动输入…」可指定列表之外的名称（须与页面显示完全一致）。若所选画质在当前直播间不存在，会自动回退到该房间最高画质（已保存的设置不会被改写）
- **屏蔽：广告推广 / 礼物特效 / 推荐直播**：逐项开关，带 `✓` 为已启用；关闭后对应内容会立即恢复显示
- **🔄 恢复默认设置**：一键还原以上所有项

设置实时保存、跨会话记忆。布局与画质动作在每个直播间只自动应用一次，修改后的配置从下一个打开的直播间开始生效。
