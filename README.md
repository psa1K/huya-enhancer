# 虎牙直播自动切换画质

一个用于 **虎牙直播** 的用户脚本：自动跳过扫码限制的画质，并自动切换到最高画质或你指定的画质。通过 Tampermonkey / Violentmonkey 等浏览器扩展运行。

## 安装

- Greasyfork：<https://greasyfork.org/zh-CN/scripts/542837>
- 或手动安装本仓库中的 `huya-enhancer.user.js`

## 功能

- 跳过扫码解锁限制（蓝光等画质无需登录 App 扫码）
- 默认自动切换到最高画质
- 可选：自动切换到指定画质

## 自定义画质（可选）

1. 打开脚本文件，找到顶部配置：
   ```js
   const TARGET_QUALITY = "";
   ```
2. 填入页面上显示的画质名称（须完全一致），例如：
   ```js
   const TARGET_QUALITY = "蓝光4M";
   ```
3. 留空 `""` 表示自动切换到最高画质（默认行为）。

## 工作方式

脚本在进入直播间后每秒检查一次画质列表：

- 画质就位后自动停止轮询，之后可自由手动切换；
- 最长等待 30 秒，超时自动停止（弱网环境下也不会一直干扰）。

## 已知限制

- "跳过扫码"通过修改播放器内部数据实现，虎牙前端改版后可能失效。
- 页面需加载完成后才会生效；若播放器加载超过 30 秒，本次不会自动切换。
